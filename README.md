## 功能

- **双语 / 原文 / 中文** 三态切换，偏好记在本地
- **全文搜索**：输入页码（`5-24`）或关键词（`费雪效应`），跨章跳转
- **教师备注折叠**：默认收起，点开看原文与译文
- **图片放大**：点击任意图表看大图
- **键盘翻页**：`←` `→` 上一页 / 下一页
- **字号调节**、**阅读进度条**、**移动端适配**
- **打印友好**：`Ctrl+P` 直接输出 PDF，表格与图片不会被切断

## 部署到 GitHub Pages

```bash
git init
git add .
git commit -m "init: 中级宏观经济双语复习资料"

git remote add origin https://github.com/<你的用户名>/<仓库名>.git
```

然后在仓库 **Settings → Pages**：

- Source 选 `Deploy from a branch`
- Branch 选 `main`，目录选 `/ (root)`

## 体例说明

- **原文**：逐字照录，保留原页拼写与语法错误，仅在「要点」中指出，不在原文中改动
- **中文对照**：逐句直译，不合并不省略
- **页码**：`章-页`，如 `3-27` 表示第 3 章第 27 页
- **图表**：原生图表按原位裁剪；用形状绘制的图形与公式对象用整页截图
- **动画分帧**：同一图形的不同步骤逐页保留，标注「第 n 帧」
